# Clase 17 · La clase de los chicos

Programación diaria y tareas para el alumnado: talleres, fichas, juegos interactivos y PDF para imprimir.
Web educativa gratuita, sin datos personales.

Los pictogramas son de [ARASAAC](https://arasaac.org) (autor: Sergio Palao; propiedad: Gobierno de Aragón;
licencia CC BY-NC-SA).

Para probarla en local: `python3 -m http.server` en esta carpeta y abrir `http://localhost:8000`.
